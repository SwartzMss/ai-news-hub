## 已修复的问题

1. **最终结果混入过程说明**：Adapter 忽略 `agentMessage.phase`，合法最终 JSON 被 commentary 前缀污染。现在过程消息只作为匹配 Turn 的日志，优先选择 final_answer；旧版/未知 phase 保留兼容，只有过程消息时不能成功。覆盖提前终态、无 phase、未知 phase 和明确最终消息优先等场景。
2. **探针消息与凭据边界**：独立探针可能被最终消息后的 commentary 覆盖，或把仅在 commentary 出现的 marker 当成功；此前还直接继承整个父进程环境。现已区分消息 phase，并与 Backend 共享环境白名单。管理/发布凭据不能进入子进程，模型认证和运行所需变量保持允许。同步了独立部署所需的内部共享模块，并实际复制到临时独立布局运行成功。
3. **目标变化后的误导写操作**：已在旧仓库发布的报告，更换目标后仍显示“核对归档记录”，实际可向新目标写入。现在按当前 repository/branch 的成功记录展示状态；新目标需明确点击归档，已有当前目标记录的刷新只调用 GET，本地历史逐条标明目标。

以上问题均先添加失败回归，再修复并验证。迁移 1–4 的 SQL/checksum 未修改，没有删除数据库或真实数据规避问题。
