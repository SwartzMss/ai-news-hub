# 公共用户隐私说明（上线前待确认）

此文档是 Issue [#163](https://github.com/SwartzMss/ai-news-hub/issues/163) 的草稿。上线前由运营者确认主体名称、隐私联系邮箱、实际域名、备份/删除期限和适用地区要求，并将确认后的内容发布在网站。当前认证关闭；本草稿不是已生效的隐私政策。

AI News Hub 的公开新闻、RSS 和 Newsletter 可以独立使用。公共账户启用后，站点会在 Cloudflare D1 保存邮箱、密码派生值、邮箱验证状态和时间、账户时间；登录时保存哈希化 Session Token 与过期时间。注册、找回和登录保护会保存带有效期的哈希化限流键，不保存原始挑战 Token。收藏保存文章完整快照、收藏时间和自定义分类，只对当前账户展示。邮箱用于验证、找回密码和必要的账户通知，不会自动订阅 Newsletter。

认证邮件通过 Resend 发送。站点使用仅限当前站点、HttpOnly、Secure、SameSite=Lax 的登录 Cookie。账户数据导出需要登录并再次输入当前密码，文件包含账户基本资料、收藏快照和分类；不包含密码派生值、Session Token、一次性邮件 Token 或限流记录。

**当前版本暂不提供账户注销。** 生产开放注册之前必须明确用户如何申请删除、运营者如何核验身份与执行删除、备份中的个人数据保留多久，以及从旧状态恢复时如何避免已删除账户重新出现。当前没有独立自动备份服务；D1 Time Travel 的实际保留窗口取决于 Cloudflare 计划。上述期限和请求渠道未确定前，不应把本草稿作为开放注册的隐私承诺。

如需提出隐私请求，运营者应在上线前公布专用联系邮箱：**待填写**。不要通过公开 Issue 发送密码、Token、Cookie 或完整数据导出文件。
