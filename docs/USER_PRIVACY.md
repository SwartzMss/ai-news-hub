# 公共用户隐私说明（上线前待确认）

此文档是 Issue [#163](https://github.com/SwartzMss/ai-news-hub/issues/163) 的公开说明草稿。上线前由站点运营者确认主体名称、隐私联系邮箱、实际域名、备份保留规则和适用地区要求，并将确认后的内容放到网站可访问页面。未核实前不得把本草稿当作已生效的隐私政策。

AI News Hub 的公开新闻、RSS 和 Newsletter 可以独立使用。创建公共用户账户时，站点保存邮箱、密码派生值、邮箱验证状态和时间、账户时间；登录时保存哈希化 Session Token 与过期时间。注册、找回、登录保护会保存带有效期的哈希化限流键，不保存原始挑战 Token。收藏会保存文章的完整快照、收藏时间和自定义分类；这些内容只对当前账户展示。账户邮箱用于验证、找回密码和必要的账户通知，不用于新闻邮件订阅，除非用户另行订阅 Newsletter。

数据存于 Cloudflare D1；认证邮件通过 Resend 发送。站点使用仅限当前站点、HttpOnly、Secure、SameSite=Lax 的登录 Cookie。账户数据导出需要登录并再次输入当前密码，下载文件包含账户基本资料、收藏快照和分类；不包含密码派生值、Session Token、一次性邮件 Token 或限流记录。账户页面可用当前密码永久注销账户；在线用户、Session、收藏及分类会级联删除。若私有备份墓碑无法写入，注销暂不可用，避免恢复旧备份时重新出现该账户。

生产备份计划为每日一次、私有 R2 保留 30 天；D1 Time Travel 的实际窗口由 Cloudflare 计划决定。注销时另存仅含随机用户 ID 与删除时间的墓碑，保留至少 90 天，用于从旧备份恢复时剔除已注销账户。超过保留期限的备份和墓碑由 R2 生命周期规则删除。若实际配置与这些期限不同，先修改说明、服务配置和告知内容，再开放注册。必要的安全事件调查、法律义务或平台自身保留可能另有期限，应由运营者核定。

用户可在账户页导出数据或注销。若无法登录、注销接口不可用，或需提出隐私请求，请联系运营者在上线前公布的专用邮箱：**待填写**。运营者应确认身份后处理请求，不应要求用户通过公开 Issue 发送密码、Token、Cookie、完整导出文件或其他私人信息。
