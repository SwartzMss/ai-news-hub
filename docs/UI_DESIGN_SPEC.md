# AI News Hub — UI / UX 规范

本规范描述当前公共阅读站和管理后台的交互与视觉约定。正式页面分别位于 `apps/web` 和 `apps/admin`，启动方式见 [公共站](PUBLIC_WEB.md) 与 [管理后台](ADMIN.md)。Cloudflare 实际上线与原生 Linux 服务验收仍待完成。

## 页面与入口

| 页面 | 当前路径与用途 |
| --- | --- |
| 公共首页 | `/`，选择话题并查看对应最新简报 |
| 话题页面 | `/topics/<id>/`，每个任务对应独立话题；旧频道页保留为话题目录 |
| 来源详情 | `/topics/<id>/news/:key/`，事实摘要、推断、精确引文和原文链接；兼容旧来源 URL |
| 历史归档 | `/archive/` 话题目录，`/topics/<id>/archive/` 日期/版本归档 |
| 输出 RSS | `/rss/topics/<id>.xml` 独立订阅，兼容原全站 Feed |
| 私有管理后台 | Backend 的 `/admin/`，Task → Run → Thread / Turn |

公共站每个路由都生成实际 HTML，无 JavaScript 也能阅读；浏览器脚本切换话题与明暗模式，localStorage 仅保存偏好，不缓存凭据或私有数据。后台使用 hash 导航，实际私有读写均经受保护的 `/api`。公开导航不提供管理入口。

## 研究、审核与发布

首次本机页面设置密码/确认密码 → 管理员登录 → 选择 Codex 主题新闻研究 → 填写主题和初始 prompt → 查看 Run 内回复与来源 → 多轮补查/筛选 → 显式生成待审核日报 → 人工核对原文、摘要和时间 → 批准此版本 → 单独归档 GitHub。

- 主题与会话属于具体 Run，不提供独立一级 Agent 工作台。
- 研究轮展示原始 prompt 和 Codex 回复；最终生成成功后该 Run 固定，修订需新建研究。
- 每轮明确提示模型额度消耗；网络不确定时锁定输入并重试原 payload/幂等键。日志翻页保留输入和待重试请求。
- 执行状态、错误、Thread/Turn、分页日志和生成结果分开呈现。未生成日报、认证失效、服务关闭与执行失败有独立提示。
- 工具审批仍拒绝，没有工具审批交互界面；日报人工批准为独立业务操作。
- 发布默认关闭，展示配置目标与历史。批准绑定当前内容哈希；归档失败可显式重试，已有当前目标成功记录的刷新只读本地记录。

## 内容与来源

事实摘要、分析推断、精确引文和来源分别展示。原始发布时间、事件时间与抓取时间独立，未知显示“未知”，不能以抓取时间替代发布时间。

`validated` / `source_only` 表示结构与来源引文关联，仍待人工审核，不显示为“已核实事实”。没有可验证来源时不生成可发布结果，不伪造点赞、评论或热度。

模型和来源文本按文本转义，不执行任意 HTML。原文链接限制 HTTP(S)，新研究来源由 Backend 进一步执行公网 HTTPS 校验。历史版本保留原正文，来源详情展示当前保留的来源内容；公共站只读取已批准的归档 JSON。

正式无数据时展示空状态。显式 demo 使用独立测试样本，页面/RSS 标记 DEMO 并禁止索引；正式构建拒绝测试标记，不把示例域名当作已上线站点。

## 视觉约定

公共站使用白色页面、深灰正文与绿色选中状态，桌面话题导航置于左侧并随页面滚动保持可见，窄屏恢复顶部下划线导航，单列资讯用细分隔线组织。内容区只保留一个话题标题和日期；列表标题/摘要控制行数，全文在详情中保留。Admin 使用独立的浅色工作台样式：

- 页面灰 `#f5f7fa`、白色表面 `#ffffff`、正文 `#17212f`、辅助文字 `#64748b`、边框 `#e2e7ee`、操作绿 `#16765c`。状态同时显示文字与圆点，不只依赖颜色。
- 字体使用系统本地中文无衬线字体，无远程字体、图片或图标依赖；图标为内联 SVG，装饰图标不进入可访问名称。
- 桌面固定侧栏、位置导航与内容区；窄屏改为可见的顶部导航，保留任务、设置和退出。页面单列时表格/日志局部滚动，不撑宽页面。
- 登录/首次初始化采用品牌介绍和表单双栏，手机精简介绍；首次仍只填写设置密码与确认密码。
- 系统概览展示真实任务计数与执行趋势；任务总览显示配置，直接提供运行/停止、编辑、定时启停、确认删除和自动发布开关。新建/编辑在独立对话框完成；运行历史统一在“运行与结果”查看。
- Run 默认显示研究会话，日志与运行信息放入独立标签。标签支持方向键及 Home/End，切换标签与日志翻页保留研究草稿和待重试请求。最终原始 JSON 在运行信息内，日报提供独立来源预览与批准区。
- 设置分为模型/执行、GitHub 归档、安全三组，分区导航滚动定位；运行参数统一保存，密码独立更新，已存 Token 不回显。
- 交互控件有可识别标签、禁用/提交状态和可见焦点；提供跳到主要内容的入口，遵循减少动态效果偏好。主要按钮和输入高度至少 44px。

## 认证与部署边界

登录后临时 Bearer 会话只在当前页面内存，刷新需重新登录，服务端历史保留。退出、Token 失效或管理关闭时清除私有视图；轮询顺序执行，导航/退出取消旧请求并忽略迟到响应。

Backend 默认只监听 Linux 主机回环。管理后台构建于 `dist/admin`，公共输出仅为 `dist/web`，两者分开部署。Cloudflare 不运行 Backend、Codex 或 SQLite，不接收 Admin 与运行日志。

## 尚未实现

自动退避、SSE、工具审批交互、公开搜索/收藏和版本差异对比尚未实现。后续范围以 [路线图](ROADMAP.md) 为准，不把设计意向描述为已有功能。

系统设置由独立管理导航进入：GitHub 目标/Token、Codex 路径/模型、执行限制及日志写入数据库。已存 Token 不回显；留空保留，替换/清除明确操作。任务/归档忙碌时拒绝保存，revision 冲突提示重新核对。管理员密码修改验证当前凭据并撤销其他会话。
