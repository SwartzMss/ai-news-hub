# 任务管理

任务列表提供新增、编辑、删除、立即执行、停止执行与定时启停。每个用户任务保存主题、有序 Prompt、执行计划、时区及自动发布开关。

每次执行冻结配置，顺序运行研究 Prompt 并恢复同一 Thread，末尾追加结构化日报生成轮。失败或停止后不继续后续轮次。后台仅展示执行记录，不提供交互式追问。来源验证仍由 Backend 完成，凭据不传给 Codex。

自动发布关闭时结果待审核；开启时通过校验后记录自动授权并复用 GitHub 归档提交。推送失败独立记录且可重试。公共站构建由归档仓库的外部部署流程负责。

计划支持手动、单次、间隔、每日、每周；默认 Asia/Shanghai。同任务不重叠，重启不补跑。删除仅移出任务列表，保留执行、报告和发布审计。

实现分为后端配置与迁移、调度与执行串联、前端任务管理和集成验收。历史预定义任务保留兼容，不把旧工作流误标为用户配置任务。

编辑器仅保留“任务主题”，同时保存为任务显示名称与 Codex 研究主题。卡片分别呈现定时状态与当前执行状态，仅显示运行或停止一个主要操作；编辑、定时启停和删除归入“更多”。暂停定时不影响手动立即运行。最近执行提供结果入口；历史与诊断入口不展示。

任务配置与执行结果分开：任务总览负责配置、计划和启停；独立“运行与结果”提供跨任务历史、任务/状态筛选及分页，包含已删除任务的历史。详情默认展示最终日报，Prompt 输出和日志为次级标签，支持审核与发布。研究 Prompt 完成后额外追加的日报生成标为系统步骤；来源抓取校验失败时不生成可审核/发布日报，研究记录仍可查看。
